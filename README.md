# 🐧 Linux User Management Script

A Bash script that automates basic Linux administration tasks, including user and group creation, directory management, and permission configuration.

## ✨ Features

- 👤 Creates user accounts with home directories.
- 👥 Creates groups for different departments.
- 📁 Organizes directories.
- 🔐 Configures ownership and permissions.

## 🚀 Usage

```bash
git clone https://github.com/joaothomazpedro/linux_user_script.git
cd linux_user_script
chmod +x user_tool.sh
sudo ./user_tool.sh
```

> **⚠️ Warning:** This script creates system users and directories. It also uses a hardcoded initial password. Review the code and test it in a virtual machine before running it.
